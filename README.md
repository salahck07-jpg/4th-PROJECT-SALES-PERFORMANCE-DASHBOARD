# 📊 Sales Performance Dashboard – Microsoft Excel

## 📌 Project Overview

An interactive **Sales Performance Dashboard** developed using Microsoft Excel to analyze sales performance, revenue, costs, profit, orders, customers, and profit margin.

The project demonstrates practical skills in **data cleaning, data analysis, PivotTables, KPI creation, data visualization, and interactive dashboard design**.

## 🔍 Analysis Process

**1. Data Preparation**
Cleaned and organized the raw sales dataset for analysis.

**2. Data Analysis**
Used PivotTables and Excel formulas to summarize and analyze the data.

**3. KPI Creation**
Created KPI cards to display important business metrics such as sales, profit, orders, customers, and profit margin.

**4. Visualization**
Created charts to make sales and performance trends easier to understand.

**5. Dashboard Development**
Combined the analysis into an interactive Excel dashboard using slicers and visual elements.
